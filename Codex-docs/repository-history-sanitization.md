# 公開Git履歴の一次資料除去記録

実施日: 2026-08-12

## 対象

- リポジトリ: `kiseki-lab/2026-memory-map-report`
- 公開ブランチ: `main`、`moriumi/add-readme`
- 除去対象: `memory-map-site/思い出マップゼミ.md`

## 理由

除去対象は活動内容を確認するための一次資料であり、メンバー名、役割、内部議論、埋め込み画像などを含む。公開サイトの入力資料としては有用だが、公開リポジトリへ原文を収録する必要はない。

## 方針

1. 原本はローカルのGit管理外ディレクトリ `sources/` へ退避する
2. 通常の削除コミットだけでなく、公開ブランチの全履歴から対象パスを除去する
3. 履歴再構築は現在の作業ツリーとは別の一時ミラーで行う
4. `main` と `moriumi/add-readme` を強制更新する
5. リモート参照と新規クローンを使い、対象パスとオブジェクトが到達不能であることを検査する

## 注意

- 履歴再構築後はコミットIDが変わる
- 既存クローンを使うメンバーは、再クローンまたは新しい履歴への付け替えが必要になる
- GitHub上のフォーク、第三者の既存クローン、検索エンジンや外部キャッシュは、この操作だけでは削除できない
- 機密トークンが含まれていた場合は、履歴除去とは別に失効・再発行が必要になる

## 検証項目

- 公開ブランチのツリーに対象パスが存在しない
- 全公開参照の履歴から対象パスを検索して0件になる
- 対象ファイルの旧blobが公開参照から到達不能になる
- 新規クローンに対象ファイルが存在しない
- `Codex-docs/` の公開用文書と、`sources/` の非公開一次資料が分離されている

### GitHub内部参照に残る課題

閉じたPull Request #1の内部参照 `refs/pull/1/head` は、履歴再構築前のコミットを保持している。GitHubのPull Request参照は通常の `git push --force` では更新・削除できないため、完全なパージにはGitHub Supportへ次を依頼する必要がある。

- リポジトリ: `kiseki-lab/2026-memory-map-report`
- 対象Pull Request: `#1`
- 残存参照: `refs/pull/1/head`
- 依頼内容: 履歴再構築前のコミット、Pull Request参照、キャッシュされた差分表示から対象ファイルを削除

公開ブランチの通常の履歴と通常クローンからは除去済みだが、このSupport対応が完了するまでは「GitHub上の全参照から完全に消去済み」とは扱わない。
