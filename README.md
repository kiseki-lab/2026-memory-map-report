# 2026 Memory Map Report

2026年春、麗澤大学で活動した「思い出マップ」自主企画ゼミの活動報告サイトです。

## サイト

リポジトリ直下の `index.html` をブラウザで開くか、次のコマンドでローカルサーバーを起動します。

```bash
python3 -m http.server 4173
```

公開サイト: https://kiseki-lab.github.io/2026-memory-map-report/

主な掲載内容：

- Home Coming Dayで行ったアナログ思い出マップの体験
- スマホ撮影、手書きOCR、レビュー、データ配信、Unity表示の仕組み
- 2026年3月28日から6月20日までの活動経緯
- 3D Webビューアと関連する公開GitHubリポジトリ

## 公開時の注意

`sources/` は議事録やチャット履歴など、事実確認のための一次資料置き場です。
私的な会話、メールアドレス、出欠、来場者データなどを含む可能性があるため、
`.gitignore` で公開対象から除外しています。
