# 思い出マップ 活動タイムライン（開発用）

最終更新: 2026-07-25

この文書は、活動報告サイトに載せる内容を決めるための編集台帳です。議事録、LINE、Slack、関連する公開GitHubリポジトリの履歴を照合し、日付が確認できた出来事を並べています。

公開原稿にするときは、個人名、メールアドレス、限定公開URL、発言者を特定できる情報を出しません。SlackやLINEの文章も原文のまま転載せず、事実関係だけを要約します。

## 表示ラベル

- `活動`: 授業、制作、準備を行った日
- `決定`: 方針や仕様が決まった日
- `苦労`: 試行錯誤や行き詰まりがあった日
- `達成`: 動くものができた、課題を解消した日
- `本番`: 展示・イベント当日
- `今後`: 2026-07-25時点では未実施の予定

## 実装用データ構造

タイムラインをコンポーネントへ直書きせず、次の形のJSONまたはTypeScriptデータとして管理します。

```ts
type TimelineEntry = {
  id: string;
  date: string;
  endDate?: string;
  phase: "準備" | "企画" | "制作" | "本番" | "展開";
  types: Array<
    "activity" | "decision" | "struggle" | "achievement" | "event" | "future"
  >;
  teams: Array<"all" | "analog" | "technical" | "operations">;
  title: string;
  summary: string;
  actions?: string[];
  decisions?: string[];
  struggles?: string[];
  achievements?: string[];
  takeaway?: string;
  media?: Array<{
    kind: "image" | "video" | "screen-recording" | "commit";
    src: string;
    alt: string;
    caption?: string;
  }>;
  sourceRefs: string[];
  publicStatus: "confirmed" | "planned";
};
```

`sourceRefs` は編集確認用です。画面にはそのまま表示せず、公開用の「参照資料」欄へまとめる場合も内部URLや個人情報を除きます。
