# 春学期 思い出マップ自主企画ゼミ 活動報告サイト

このフォルダは、麗澤大学の春学期「思い出マップ自主企画ゼミ」の活動報告サイト案です。
既存の思い出マップ成果物は外部リンクとして扱い、このサイトでは成果物と4月から7月までの活動内容を紹介します。

## 見る方法

`index.html` をブラウザで開いてください。

背景素材は次の順で読み込みます。

1. `IMG_8439.gif`
2. `IMG_8439.MOV`
3. 読み込めない場合は `assets/poster.svg`

Vercelなどに公開する場合は、`IMG_8439.gif` またはWeb向けに軽量化した動画を同じ階層に配置してください。
