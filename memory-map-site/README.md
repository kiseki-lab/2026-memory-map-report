# 春学期 思い出マップ自主企画ゼミ 活動報告サイト

麗澤大学の2026年春学期「思い出マップ」自主企画ゼミの活動報告サイトです。
Home Coming Dayの体験、アナログ地図と3D表示をつないだ仕組み、4月から7月までの活動、
振り返り、公開成果物を紹介します。

活動タイムラインは、デスクトップでは左側の小型カレンダー、モバイルでは横スクロールの日付レールと連動します。
現在読んでいる活動だけをカレンダーから線で結び、通常の時系列記事としても読めるようにしています。

## 見る方法

リポジトリのルートからローカルサーバーを起動してください。

```bash
python3 -m http.server 4173 --directory memory-map-site
```

ヒーロー背景は `IMG_8439.gif`、各成果物の説明には `assets/` 内の公開用スクリーンショットを使用しています。
管理画面のスクリーンショットは、プライバシーに配慮したダミーデータ版です。
