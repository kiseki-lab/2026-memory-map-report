麗澤大学 / 春学期 活動報告

思い出を集め、地図にして、共有する。

春学期の自主企画ゼミでは、Home Coming Dayに向けて、 麗澤大学の思い出を集めるアナログMAPと、3D・Web表現を組み合わせた成果物づくりに取り組みました。 このサイトでは、成果物と4月から7月までの歩みをまとめます。

Purpose

このゼミで目指したこと

私たちは、大学生活や卒業生の記憶を、場所と結びつけて残すことに注目しました。 思い出は個人のものですが、地図に重ねることで、誰かの青春や経験を他の人もたどれる形にできます。

春学期は、HCDに向けた企画、アナログ地図の準備、カテゴリ設計、Web・3D表現、 当日の運営と振り返りを進めました。完成した「麗澤思い出マップ」は、活動の成果であると同時に、 今後さらに思い出を集めていくための土台です。

April - July

春学期の活動記録

4月

企画の再確認と役割決め

Memory Mapの目的を再確認し、Home Coming Dayに向けて何を準備するかを整理しました。 地図印刷、大学の線引き、ジャンル説明、ラミネート、買い出し、Web作成など、必要な役割を洗い出しました。

  • Memory Mapの目的と今後の計画を共有
  • HCDに向けた展示内容と役割を整理
  • Next.js、Supabase、Three.jsなどデジタル表現の方向性を検討
5月

展示イメージと準備内容の具体化

HCD当日の見せ方を固め、アナログ班とデジタル班で作業内容を具体化しました。 キャッチコピーや作業日程、印刷・ラミネート、会場レイアウトなど、当日に向けた準備を進めました。

  • 「あなたの青春が同じ地図上で出会う。離れていても思い出はキャンパスに。」を決定
  • 1974・1979・1984・2005・2025の年代地図を準備
  • A3印刷、丸机、導線、準備日程を調整
6月

HCD実施と振り返り

HCDに向けて当日イメージ、メンバー、ルールを確認しました。 思い出のジャンルは、恋愛、友情、学業、部活、行事、その他に整理し、色分けして貼れる仕組みにしました。 実施後は良かった点と改善点を振り返りました。

  • ジャンルと貼り方のルールを決定
  • 入口展示や当日の仕事分担が好評
  • 導線説明、報連相、過去の麗澤理解を改善点として整理
7月

次のイベントとWeb報告へ

HCDで得た成果と反省をもとに、現麗澤大学生向けのイベント開催とWeb作成を決定しました。 春学期の活動を振り返り、成果物だけでなく、そこに至るまでのプロセスを報告できる形にまとめています。

  • 現麗澤大学生向けイベント開催を決定
  • 「思い出記入」以外のアクションも検討
  • 活動報告サイトとして春学期の流れを整理

Learning

活動を通して得たこと

記憶を共有できる形にする

個人の思い出を場所と結びつけることで、他の人も理解しやすい情報に変換できました。

地図をコミュニケーションの場にする

地図は位置を示すだけでなく、会話や発見を生むためのインターフェースになると分かりました。

成果物を更新できる土台にする

今後も思い出を追加していくことで、より多くの人が関われるアーカイブへ発展できます。
